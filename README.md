<h2>JSON Studio & Code Generator workbench featuring an IDE-inspired dark mode interface:</h2>
<h3>1.JSON Formatter & Minifier:</h3> Configurable indentation (2-space, 4-space, tabs), key sorting (alphabetical ascending/descending), null-stripping, and single-click minification with byte savings metrics.
<h3>Dart Model Generator:</h3> Generates clean, null-safe Dart classes complete with factory fromJson(), Map toJson(), copyWith(), and optional Equatable integration.
<h3>TypeScript Interface Generator:</h3> Converts payloads into strongly typed TypeScript interface or type aliases, supporting nested type extraction, array union types, readonly modifiers, and JSDoc annotations.
<h3>PHP Class Generator:</h3> Generates modern PHP (7.4, 8.0+, 8.2+) classes with constructor property promotion, strict typing, fromArray(), fromJson(), and JsonSerializable support.
<h3>C# Model Generator:</h3> Supports class and record architectures, System.Text.Json / Newtonsoft.Json property mappings, PascalCase formatting, and nullable reference types.
<h3>Interactive Parsing & Validation:</h3> Real-time syntax parser highlighting exact line and column errors, paired with a smart Auto-Fix engine that corrects trailing commas, unquoted keys, single quotes, and Python dictionary literals.
<h3>Interactive Tree Inspector & Payload Metrics:</h3> Collapsible node explorer with search filtering and deep payload inspection (depth levels, primitive type breakdowns, and bandwidth savings).
